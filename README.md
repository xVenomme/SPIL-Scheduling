# Dispense Scheduling SPIL

Pagina interattiva per esercitarsi sugli algoritmi di scheduling del corso di Simulazione dei Processi Industriali e Logistici (SPIL).

Per ognuno dei 13 algoritmi: idea in parole semplici, ricetta, esercizio modificabile risolto passo per passo con Gantt, alberi di enumerazione, piano dei tempi e curva di Pareto.

| # | Algoritmo | Problema |
|---|-----------|----------|
| 1 | SPT | 1 \|\| ΣC |
| 2 | WSPT | 1 \|\| ΣwC |
| 3 | EDD | 1 \|\| Lmax |
| 4 | Moore | 1 \|\| ΣU |
| 5 | Lawler | 1 \| prec \| hmax |
| 6 | Branch & Bound | 1 \| r \| Lmax |
| 7 | Smith | 1 \| Tmax = 0 \| ΣC |
| 8 | Smith modificato | 1 \| Tmax ≤ Δ \| ΣC |
| 9 | Gilmore e Gomory | 1 \| s_ij \| Cmax |
| 10 | Johnson | F2 \|\| Cmax |
| 11 | Piano dei tempi + A* | J2 \| utensili \| Cmax |
| 12 | Shifting bottleneck | Jm \|\| Cmax |
| 13 | Visita in profondità | Fm \|\| Cmax · F |

## Come aprirla

È un unico file `index.html`, senza installazioni: aprilo nel browser oppure pubblicalo con GitHub Pages
(Settings → Pages → Branch `main`, cartella `/ (root)`).
